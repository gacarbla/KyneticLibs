# @kyneticweb/dom

## 0.2.0

### Minor Changes

- First public release of the Kynetic framework.
  
  - Signals, computed values, effects, batching and ownership.
  - Fine-grained DOM renderer with a JSX compiler, context, lists, conditionals and portals.
  - Typed router with guards, lazy routes and `preload()`.
  - Typed i18n with plurals and locale formatting.
  - Forms with live validation and accessible fields.
  - SSR with `renderToString`, async pending boundaries, in-order and out-of-order streaming, and hydration.
  - DOM testing helpers and a devtools panel.
  - A 20-component UI kit with size, tone and variant parameters.

### Patch Changes

- Updated dependencies
  - @kyneticweb/reactive@0.2.0
